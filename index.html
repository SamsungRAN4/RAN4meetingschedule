Chapter 1

它不是聊天机器人

市面上能聊天的 AI 很多。Hermes 不一样：你不在的时候它也能干活，它记得你上个月说过什么，它学会你的工作方式之后不会再忘。

01

持久记忆

跨会话记住 GitHub、公众号、SSH。换了新会话，它自动加载一切直接干活。那一刻它不是工具，是搭档。

02

Skill 自成长

从经验中自动学习可复用 Skill。教一次终生不忘。做完复杂任务自动保存，下次同类任务直接复用。

03

情报搜集 + 定时任务

每天 4点/7点/7点半自动搜索新闻、分析趋势、交叉验证、推送到飞书。你醒来读结果就行。

04

飞书接入

聊天习惯友好，像跟同事说话一样发指令。公司里随时开聊、共享方便。终端 SSH、飞书群推送全覆盖。

Chapter 2

三类 Agent，不是一类东西

聊天机器人、桌面编程 Agent、网关 Agent——它们是三个维度的工具，不是竞争关系。

💬 Chatbots

聊天机器人

ChatGPT、豆包、DeepSeek Chat。你问它答。关掉一切归零。无记忆、无工具、无自主性、不会替你干活。

✅ 快速问答 · ❌ 无记忆 · ❌ 无工具
🖥️ Desktop Agents

桌面编程 Agent

Codex、Claude Code、Cline SR。在 IDE/终端里写代码、重构、修 bug。但不会搜情报、没有定时任务、不记得你、不自成长。Cline SR 还被三星防火墙限制，没法用手机操控。

✅ 代码生成 · ❌ 情报 · ❌ 定时 · ❌ 记忆 · ❌ 自成长
🌐 Gateway Agents

网关 Agent

Hermes、OpenClaw。连接消息平台、终端、API、Cron，全平台覆盖。其中 Hermes 是唯一有长期记忆、Skill 自成长、情报搜集能力的网关 Agent。

Chapter 3

Hermes 独有的六件事

其他 Agent（Chatbot、Codex、Cline SR、OpenClaw）至少缺以下 4-6 项

🔍

情报搜集

web_search + web_extract + 交叉验证 + 结构化报告。不是编答案，是真搜索、真抓取、真验证。Codex 和 Cline SR 不会这个。

⏰

定时任务

内置 Cron，每天 4点/7点/7点半自动跑。没人守着也干活。桌面 Agent 没有这个能力。

🧠

长期记忆

跨会话记住你的名字、邮箱、SSH配置、文章风格。换了新会话自动加载，不用重复说。Codex / Cline SR 每次从头问起。

🌱

Skill 自成长

做完复杂任务自动保存为 Skill，下次直接复用。越用越强，不是越用越旧。OpenClaw 要人写 Skill，Cline SR 教了也记不住。

🔓

开放架构 + 翻墙

模型自由切换、代理商翻墙、SiliconFlow 接第三方 API。Cline SR 被三星防火墙锁死，什么都出不去。

📱

飞书手机操控

在公司用飞书发指令，像跟同事说话一样。Cline SR 只有 VS Code 插件，没法用手机操作。

"Chatbot 能聊但不能干。Codex 能写但不会搜。Cline SR 被墙挡住。
OpenClaw 有平台但不自成长。
Hermes 是唯一一个六项全能的。"

Chapter 4

📱

日常对话，像跟同事聊天。Markdown、图片、文件发送。

🖥️

终端

⏰

Cron
